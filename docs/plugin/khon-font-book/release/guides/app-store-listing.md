# KhonFontBook 安装与使用

版本 0.2.0 · 作者 KhonChi

KhonFontBook 用于管理 Halo 站点的字体，为中英文设置搭配，并通过选择器将字体应用到主题中的指定文字。

## 安装

运行环境为 Halo 2.27.0、Java 21、Linux x86_64、glibc ≥2.38，系统提供 `/usr/bin/prlimit`，临时目录可写且允许执行。解析组件随插件提供，不需安装 Python、FontTools 或另配解释器；其他平台尚未验证。

1. 备份 Halo 数据和附件，将插件 JAR 上传到 Console「插件」，然后启用。
2. 工作台会检查实际状态，正常显示「字体解析可用」和「字体存储已准备」。设置页只保留默认关闭的主题字体注入开关，无需填写解释器路径或存储策略。旧配置中的 Python 路径和 `KHON_FONT_BOOK_PYTHON` 不再影响解析。
3. 首次进入工作台或导入前，插件自动准备专用 local 附件策略，无需手工创建或填写新策略名。已有有效配置继续沿用；名称被不兼容资源占用时，插件选择并保存独立名称，不覆盖原资源。默认使用专用子目录、20MB 上限和空文件类别列表，字体签名及元数据由插件检查。全站默认策略与 CORS 配置不变。
4. 配置 Halo 的 `external-url`，确保 Halo 能匿名读取该地址下的本地 `/upload/` 字体文件。当前支持同源本地附件，不支持私有文件、跨域存储或重定向地址。

普通账号需授予「查看字体资源」才能访问工作台，导入、编辑和删除还需要「管理字体资源」。若已有附件导入仍返回 403，先核对角色及[版本说明](release-notes.md)中的后续修复，不扩大为全站通配权限。

## 升级与恢复

升级前备份数据库、Halo工作目录和附件，保留原JAR及原配置。上传新包后检查工作台的实际解析/存储状态并加载原字体预览；同版本替换后若仍显示旧解析器或旧设置，重启Halo并重新登录、刷新后台，再确认新包已加载，不能只看STARTED或版本号。

已有有效策略、字体地址和业务ID继续使用；旧解释器值保留但不参与解析，无需重新上传字体。若失败，先停止写入，检查错误原因；回退旧JAR时须恢复旧版所需的运行环境并重启Halo。需要恢复备份时同时使用相同时间点的数据库、配置和附件，避免把新记录与旧文件混合。插件不会自动删除或搬迁物理字体。

恢复后确认插件已启用，等待工作台实际状态就绪，检查原字体预览、配对方案和主题规则后再继续修改。数据库备份及恢复方式须与实际部署一致；外部数据库不能只靠复制Halo工作目录恢复。

## 导入与配对

在「工具 → KhonFontBook → 字体库」导入 WOFF2 或 TrueType TTF，填写字体来源和许可。插件保留原格式，读取字重、样式及字符覆盖，预览时按需加载文件。

需要中英搭配时，在「配对方案」中分别选择中文与西文字体，使用两侧共有的字重和样式，并设置回退字体。也可以在规则中直接选择一个字体族。

支持静态单色字体，单文件上限 20 MiB。暂不支持 OTF、字体集合、变量字体、颜色字体、格式转换和自动子集化。插件不附带字体文件，元数据检查不能代替字体授权确认。

## 设置主题规则

在「主题规则」中新建规则，选择主题、页面范围和字体目标，填写选择器并保存。然后到插件设置中开启「主题字体应用」，刷新对应页面。

| 写法 | 含义 |
| --- | --- |
| `.a, .b, #title` | 用半角逗号选择多个独立目标 |
| `.a .b` | 选择 .a 内部的 .b 后代 |
| `.a.b` | 同一元素同时具有两个 class |
| `.a > .b` | 选择 .a 的 .b 直接子元素 |

选择器支持标签、class、ID、`> + ~` 和逗号列表；不支持属性选择器、伪类、伪元素及通配符。最多 1024 字符、16 个选择器，每个选择器最多 32 个节点。

页面范围选「主页」时，只在站点根路径 `/` 应用，不包括归档和分页。指定文章或页面时，规则绑定该内容的 ID。高级编译中的页面选项只用于检查，不会改变已保存规则的范围。

默认只修改 font-family；字重和 !important 可按需要设置。若外层 class 没有改变文字，可先用「选择器穿透查询」查找文字所在的子元素，测试覆盖效果，再采用结果。采用只会填入草稿，保存规则后才生效。

诊断页面默认不运行脚本。启用脚本后，主题脚本与后台同源，可能访问本站登录态和资源，只应对信任的主题启用。字体是否加载成功仍需检查实际页面；iframe、Shadow DOM 及主题自己的内联样式可能需要另行处理。

## 停用与删除

关闭注入或停用规则后，刷新页面即可停止对应的字体应用。通过接口主动加载字体的主题或插件，需要在接入方取消引用。

删除前会检查内部和已登记的外部引用。删除插件中的字体记录会保留 Halo 附件；要移除文件，还需在附件管理中删除，并按需清理缓存与备份。未登记的外部使用无法自动查出。
