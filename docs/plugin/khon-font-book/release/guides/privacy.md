# KhonFontBook 数据处理说明

适用于 0.2.0，更新于 2026-11-03。作者：KhonChi。

## 处理的数据与用途

| 数据 | 用途与可见范围 | 保存与退出 |
| --- | --- | --- |
| 用户上传的字体文件、摘要和真实元数据 | 导入、预览、生成字体 CSS；文件通过 Halo 本地附件公开访问，不能用于保密字体 | 文件留在 Halo 附件中，直到管理员主动删除；仅删除插件记录不会删除附件 |
| 字体名称、分类、来源、授权说明、启停状态 | 管理字体与授权记录；启用且可用的字体及其来源/授权、字符覆盖等信息通过匿名 API 公开 | 保存为 Halo 扩展资源，直到有权限的用户修改或删除；请勿填写秘密、令牌或私人联系方式 |
| 字体方案、回退名称、主题 ID、页面 ID、选择器、字重与顺序 | 中英配对、按页面应用字体、内部引用保护；管理接口需要相应角色，公开方案仅暴露约定 DTO | 保留到主动删除；停用或关闭注入不删除配置或附件 |
| 外部引用的来源账号名、来源内键、目标 ID 与内容版本 | 保护已登记的外部使用；来源身份从 Halo 当前认证主体绑定 | 来源可撤销自己的登记；停用方案不释放引用；未登记的使用不会被扫描 |
| 诊断页面地址、页面文字样本与计算字体 | 在浏览器同源预览中查找文字元素和临时测试覆盖，结果仅用于诊断和填入草稿 | 未点击保存前不写入规则；关闭弹窗移除预览，临时测试样式执行后立即清理 |
| 字体专用策略和主题注入开关；历史解释器路径 | 配置字体分发，保存在 Halo 插件配置中；设置界面仅显示注入开关，历史解释器路径不再参与解析 | 保留旧值以便兼容和回退，不批量改写；凭据不应填入普通配置 |
| 自动准备的字体本地策略、配置及归属/版本标记 | 首次使用时准备独立存储，并持久化名称选择；不修改全站默认策略或用户已有有效策略 | 停用或卸载不删除这些策略及用户附件；由管理员在确认不再使用后处理 |

## 文件、网络与脚本

- 字体解析在 Halo 所在 Linux x86_64 主机/容器的本地独立工作进程中完成。内置组件提取到插件私有临时目录，正常停用时清理；每次字体任务使用独立临时目录，正常结束、失败、取消或超时后清理。文件系统拒绝清理时会记录错误；异常终止主机可能留下文件。解析组件随包提供，不调用 Python，不在安装、启用或请求过程中下载。
- 插件读取附件时只请求管理员配置的 external-url 下、配置的字体策略所属 `/upload/` 地址，限制大小和超时，不跟随重定向、不转发登录凭据。任意外站导入、跨域存储和对象存储未支持。
- 插件不接入广告、统计、遥测、账号绑定、支付或云字体服务，不向 KhonChi 或应用市场发送字体/页面数据。
- 诊断预览默认禁止页面脚本。选择运行脚本后，所加载的主题脚本与 Console 同源，可能访问本站登录态和资源；仅限信任的主题，这不是安全隔离沙箱。主题中的外部图片、样式、字体和可选脚本可能发起其自身网络请求，适用对应主题/服务的说明。
- Halo、反向代理或服务器可能按管理员配置保存访问日志、异常日志和备份；插件不能替这些组件设定保留期限。插件日志不主动记录字体字节、登录令牌或正文文本。

## 关闭、删除与撤销

1. 要停止主题字体应用，停用相关规则或关闭注入并刷新页面；外部主动接入与主题开关相互独立，需由接入方撤销。已经打开的页面与浏览器字体缓存不会被远程即时清除。
2. 删除字体/方案前先处理内部及已登记外部引用。物理字体文件还须在 Halo 附件管理中单独删除，并处理备份及可能存在的第三方缓存。
3. 禁用插件停止其运行时入口，不等于数据删除。卸载前先备份配置和附件；需要清除数据时，先处理引用并删除资源记录，再通过附件管理删除文件。
4. 使用问题和一般反馈可通过 [GitHub Issues](https://github.com/wenhsiangtech/KhonFontBook/issues) 联系维护者。仅提交脱敏信息，不要公开凭据、私人站点数据或可利用的安全细节；如仓库提供私密漏洞报告入口，应优先使用该入口。支持渠道不意味着插件自动向 GitHub 上传任何数据。
