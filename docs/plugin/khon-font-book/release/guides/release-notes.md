# KhonFontBook 版本说明

## 0.2.0 源码修复（未发布插件包）

- 修复普通字体管理账号从已有附件导入时错误返回 403 的问题；仅查看账号仍不能导入。
- 修复 9 个管理写入端点收到空请求体或 JSON `null` 时错误返回成功的问题，改为返回 HTTP 400 / `BODY_REQUIRED`。
- 修复字体库、方案和规则列表在连续刷新时，较早的响应覆盖最新数据、错误提示或加载状态的问题。
- 修复字体库刷新后残留旧预览，以及关闭或刷新预览后迟到响应仍继续加载字体的问题。刷新后需重新加载预览。

这些修复保持 0.2.0 版本声明，不改变业务标识、数据模型、客户端接口形状或字体支持范围。源码更新不表示已发布新的插件包。

## 0.2.0

此版本内置字体解析组件、自动准备专用存储，并简化安装设置。作者：**KhonChi**。

- **内置解析**：无需安装Python、FontTools或填写解释器路径，保留服务端格式、大小、字重和字符覆盖校验。
- **自动存储**：首次使用准备专用local策略，保留有效的已有配置；名称冲突不覆盖原资源，停用或卸载不删除字体附件。
- **实际状态**：设置页仅保留默认关闭的主题注入开关；工作台展示解析和存储状态，检查中或失败时暂停导入，允许刷新重试。

保留以下功能及稳定业务标识：

- **字体库**：原格式导入静态单色 WOFF2 / TrueType TTF，查看真实字重、normal / italic / oblique 样式、字符覆盖及字体预览；记录来源与许可。
- **中英配对**：分别选择中文与西文字体，按共同字重与样式建立方案，分配字符覆盖并设置回退链。
- **主题规则**：按主题及主页、文章、独立页面范围，为 class / ID 等选择器应用字体；支持规则顺序、可选字重和显式强制覆盖。
- **选择器诊断**：查询页面中真正承载文字的后代元素，测试覆盖效果，并将选定结果填入规则草稿。
- **开放接入**：提供公开字体目录、方案与样式资源，支持外部引用登记和引用删除保护。

字体解析组件随插件提供，无需外置 Python 或解释器配置；首次使用自动准备专用本地存储，保留有效的已有策略及字体附件。设置页只保留主题注入开关，默认关闭；工作台显示实际解析与存储状态，检查中或失败时暂停导入。当前解析运行范围为 Halo 2.27.0 / Java 21、Linux x86_64、glibc ≥2.38、系统 prlimit 和可写/可执行临时目录；其他平台未验证。附件读取沿用 Halo 自身配置的 external-url。升级和同版本替换步骤见安装说明。
