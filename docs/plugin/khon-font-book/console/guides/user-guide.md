# KhonFontBook 用户说明

当前版本 **0.2.0**，目标 **Halo 2.27.0**。不要求特定主题或第二个插件。解析组件随包提供，当前运行范围与字体存储前置如下。

## 1. 安装前准备

先备份 Halo 数据库、工作目录及附件；字体授权须允许上传、公开托管与网站使用。

- Halo 2.27.0 / Java 21；已验证环境为 Linux 容器，管理浏览器运行在 Windows。清单 requires≥2.27.0 只是最低声明，未验证其他 Halo 版本。
- 当前解析运行范围为 Linux x86_64、glibc ≥2.38、Java 21，系统提供 `/usr/bin/prlimit`，临时目录可写且允许执行。其他平台和架构未验证。
- 无需安装 Python、FontTools 或配置解释器。历史 Python 路径及 KHON_FONT_BOOK_PYTHON 不再影响解析；设置页不再显示解释器和策略输入项，旧配置保留用于兼容。
- 支持**单字体、静态、单色 WOFF2 / TrueType TTF，文件≤20 MiB**，包括 normal、italic 和带真实角度的 oblique。原格式保存，不转换字体；不支持 OTF，不支持集合、可变轴/实例、颜色字体或自动子集化。文件名/字体名字不能证明格式或真实字重。

启用插件后在工作台检查「字体解析可用」及「字体存储已准备」。正在检查、刷新失败、解析或存储不可用时关闭导入并显示原因，刷新成功后恢复；服务器仍会独立校验。忙时导入返回可重试提示，不排队等待另一个解析任务。策略准备不保证磁盘读写，导入和预览会实际检查。

## 2. 安装与字体专用存储

在 Console「插件」上传候选 JAR，**安装后显式启用**，确认进入 STARTED，刷新后台后打开「工具 → KhonFontBook」。全新安装初态为 DISABLED，安装成功不等于业务端点已可用。主题字体注入默认关闭。

首次访问工作台或导入前，插件自动准备字体专用local策略及配置，不需要手工创建或填写新策略名。已有有效配置直接沿用，不修改原附件或文件地址。默认名称被不兼容资源占用时，插件创建独立名称并保存选择结果；初始化尚未完成或失败时会显示原因并禁用导入，可点击刷新重试。

默认策略的配置如下；已有手动策略须满足相同大小和文件类别边界，实际选择的名称以工作台为准：

| 项目 | 示例 |
| --- | --- |
| Policy metadata.name | khon-font-book-local |
| spec.templateName / configMapName | local / khon-font-book-local-config |
| ConfigMap data.default | JSON：`{"location":"khon-font-book","maxFileSize":"20MB","allowedFileTypes":[]}` |
| 目录/大小 | 独立附件子目录；大小限制为 1 字节至 20 MiB |

空类别列表是目标 Halo 的必要配置：ALL 仍可能因 WOFF2 MIME 检测拒绝有效文件。它不负责字体校验，必须通过本插件的受控导入；持有 Halo 原生附件管理权限的用户仍可绕过此入口。**不要修改 default-policy、全站上传或 CORS 设置。**同名策略已存在时先核对，不能覆盖用户配置。

以下原生API示例仅供维护已有手动策略，并非新安装步骤；认证方式沿用Halo，不将令牌写入文档、前端或源码：
POST `/api/v1alpha1/configmaps`：
```json
{"apiVersion":"v1alpha1","kind":"ConfigMap","metadata":{"name":"khon-font-book-local-config"},"data":{"default":"{\"location\":\"khon-font-book\",\"maxFileSize\":\"20MB\",\"allowedFileTypes\":[]}"}}
```
POST `/apis/storage.halo.run/v1alpha1/policies`：
```json
{"apiVersion":"storage.halo.run/v1alpha1","kind":"Policy","metadata":{"name":"khon-font-book-local"},"spec":{"displayName":"字体专用存储","templateName":"local","configMapName":"khon-font-book-local-config"}}
```

当前支持本地同源、可匿名读取的字体附件。对象存储、私有签名 URL、跨域字体或任意 URL 导入没有验收，不放宽全站策略来迁就样本。Console 的“附件记录存在”不保证文件字节仍能读取。

## 3. 字体与方案

管理页分为四个工作区：「字体库」查看字形与字体族，「配对方案」管理中英组合，「主题规则」配置应用与选择器诊断，「文件记录」管理文件来源与引用。导入入口位于页头；存储及公开接入说明可在页面底部展开。切换工作区保留本页搜索条件。

1. 导入 WOFF2 或 TTF，填写真实来源、授权/使用范围和分类；也可选择已配置专用策略中的已有字体附件，服务器会重读并验证实际内容。
2. 同族不同字重/斜体或中文分片，导入时明确选择已有字体族。不同文件不会仅因名称相同就自动合并；相同内容重复导入返回原字形 ID，不重复上传或改归属。
3. 查看文件解析的真实 weight/style/覆盖信息，加载真实预览，保存后刷新重开。字体名出现 Bold/Italic/ExtraLight 不用于推断字重；缺字依赖回退，不虚构覆盖范围。
4. 中英配对时创建方案，选两侧真实共有的 weight/style，以及回退名称和最后一级通用字体。不能用排序两个字体名代替中英字符分配。
5. latin-cjk-v1 把英文、数字、半角标点、弯引号和破折号分给 Latin；汉字、全角标点、顿号/书名号分给 CJK。其余、缺字或加载失败的字符回退。预览可检查中文/英文/数字/标点及假名、韩文、emoji 等回退。
6. 预览只作用于预览区；禁用字形仍可手动查看文件，不表示它对外启用。禁用方案/字体保留引用。方案可停用保存待配置，但不进入公开可用目录。

0.2.0 发布包在刷新字体库时清理已加载预览，需要重新点击加载；关闭或刷新后返回的旧预览不会继续应用。字体库、方案、规则列表以最近一次刷新为准。修复的发布状态见[版本说明](../../release/guides/release-notes.md)。

**启用且可用的字体、方案和来源/许可说明可通过匿名公开 API 读取**，不要在说明中写凭据或私密信息。字体启用状态与主题注入开关是两件事。

## 4. 规则与主题生效

在「主题规则」创建「主题 + 页面范围 + 选择器 + 字体族/方案」规则；编译工具收在「高级检查」中，按需展开。主题选择使用实际安装的稳定 ID；指定文章/页面使用已发布公开内容的稳定 ID，改 slug/标题不必重建规则。私有/草稿/删除内容不提供专用规则。

- class 面向一组元素；单标题优先选择指定页面及真实、唯一、稳定的标题 ID。Earth 文章标题的验收例为 `h1.mt-3`；它不是其他主题的通用接口。`#section-introduction` 也必须由页面真实提供，插件不会自动寻找/造 ID。
- 支持 type/class/ID、后代、`> + ~` 与逗号列表。拒绝 CSS 声明片段、@规则、属性/伪类/伪元素、通配符、namespace、越界语法。选择器通过只表示语法有效，不能证明页面存在匹配元素。
- 默认只改 font-family；显式字重须为目标实际可用值。保留主题字重时浏览器可能选择邻近字形或合成粗体，例如主题 500 与资源 400/700 并不等于拥有真实 500。
- 规则按 order 升序，同序按稳定 ruleId；后输出仅在 specificity/importance 相同时占优。普通内联样式、主题 !important、子元素字体仍可能覆盖。强制覆盖须明确勾选，只对该规则的字体声明加 !important。

在「插件 → KhonFontBook → 主题字体应用」开启注入并保存，然后刷新真实主题页面。Head 按实际主题/页面上下文匹配，主题预览也使用实际解析主题；切换主题保留旧规则，但不会误用到另一主题。

确认方式：目标元素确实匹配、计算字体/字重符合配置、所需字体实际加载或渲染正确、非目标元素没有被改。Console 编译检查与 CSS HTTP 200 都不能独立证明生效。

窄屏列表保持 Halo 组件，在列表区域必要时横向滚动；整页不应横向溢出。弹窗可滚动到保存/关闭操作。发生版本冲突先刷新实际数据再继续，错误提示不代表保存成功。

## 5. 修改、停用与缓存

规则、方案、字体启停/属性或附件记录 URL 改变后，下一次渲染重新编译，并按实际 CSS 字节得到内容摘要 URL。同一地址永远不改成另一份 CSS；旧快照可能在淘汰/重启后 404，不能永久持有它。

停用规则、关闭注入或停用插件后，**新页面/刷新后的页面**不再使用对应 Head 样式。已经打开的页面和浏览器热字体缓存不会实时撤回。外部整页缓存/CDN 须清除并尊重 no-store/NO_CACHE；没有通用代理/缓存插件保证。

文件同 URL 被存储侧改写/删除不会在每次 Head 编译中重读检测。用「重新校验附件」或实际预览检查；摘要变化应新导入，不沿用旧元数据。字体 404 时依赖 font-display:swap 和回退链保持文字可读。

## 6. 引用、替换和删除

内部方案/规则与**已登记**外部使用参与检查。字体族登记保护其全部字形删除/移动；方案登记保护方案；停用不释放引用。删除受保护资源会拒绝并显示来源。

先处理规则/方案及登记，再删除字形；字形仍在时不能删除对应族/资产。删除资源记录保留 Halo 附件，包括插件上传的附件，文件回收须由管理员确认实际使用后在 Halo 附件管理中操作。未登记外部 HTML、class 或文件 URL 使用无法检测，不存在全站扫描保证。

内部替换与外部迁移确认的管理 API 见 [接入说明](../../integration/guides/integration-guide.md)。插件只更新自己的方案/规则；外部旧 ID 仍受保护。原来源须先实际迁移内容，再携旧目标/版本、新内容版本和 CONTENT_UPDATED 确认。多资源更新不是数据库事务，PARTIAL 要按 updated/remaining 修复重试；不能把修改登记当作实际外部文章已经迁移。

## 7. 权限、接入与生命周期

普通站点访问者只读可发布字体/方案及 CSS，无管理权限。字体查看使用 view 模板；管理需 view+manage；外部登记使用独立 references 模板，每个独立接入方用自己的专用来源账号。不要给接入方原始资源写入或全站管理员权限。权限变更/插件升级后应以实际身份读写验证，不能只看按钮、角色标签或 STARTED。

开放接入保存稳定 ID，每次渲染获取最新样式，按 href 去重；示例见 [integration-guide.md](../../integration/guides/integration-guide.md)。Head 开关不关闭显式接入。目标不可用或插件缺失时，调用方移除旧 class 并保留系统字体；不要把登录重定向后的 HTML 200 当作 JSON/CSS。

日常停用保留数据，但新页面停止 Head 注入，插件 API 撤销。重装后须显式启用；重启导致登录会话失效时，正常重新登录即可。

**卸载或升级前须备份数据库、Halo 工作目录和附件**。需要暂时撤销样式时优先关闭注入或停用。升级和回退步骤见[安装说明](../../release/guides/app-store-listing.md)；不要对现有站点进行未备份的卸载试验。

恢复后须等待实际插件端点就绪，并检查工作台及原字体预览。已验证的默认内嵌数据库与独立附件恢复结果不能推广到外部数据库、其他平台或任意用户数据。

## 8. 问题定位与边界

| 现象 | 处理 |
| --- | --- |
| 无法导入 / PARSER_UNAVAILABLE | 查看工作台解析原因，核对已声明的Linux架构、glibc、Java/prlimit及临时目录执行权限；无需安装或填写Python |
| FONT_STORAGE_INITIALIZING / STORAGE_PREPARATION_FAILED | 等待Halo配置和模板就绪后刷新；核对实例的配置写入及附件目录权限，不反复创建策略 |
| FONT_STORAGE_INVALID | 恢复已有策略和配置，核对独立目录、空类别列表及≤20 MiB限制；已有字体时不改名换目录，不改全站默认策略 |
| 损坏/不支持/超限 | 按错误原因提供合法静态 WOFF2 或 TTF；不通过改扩展名绕过内容检查 |
| 保存 VERSION_CONFLICT | 刷新后核对新数据再保存，不覆盖他人更新 |
| 已有附件导入返回 403 | 核对账号的「管理字体资源」权限；仅查看账号不能导入。发布前构建的普通管理账号可能遇到此问题，修复情况见[版本说明](../../release/guides/release-notes.md)，不要授予通配权限来绕过 |
| 管理接口返回 BODY_REQUIRED / 400 | 请求缺少 JSON 内容或内容为 null；按接口提交实际对象，不能将空响应视为保存成功 |
| 附件记录存在但字体没加载 | 检查实际 URL/字节、重新校验、网络、同源与浏览器字体状态，保留回退 |
| 编译成功但页面无变化 | 核对注入开关、主题/页面身份、选择器实际匹配、CSS 优先级、子元素和缓存 |
| 删除 RESOURCE_REFERENCED | 按摘要处理内部及已登记外部关系；不要绕过受控接口强删 |
| 插件停用后外部调用失败 | 停止使用旧 class、回退系统字体；恢复后重新发现，不永久保存 CSS URL |

未验证所有主题/浏览器、全部中文大字体、跨域存储、任意第三方整页缓存、多节点锁/快照共享或未知历史发布版本的数据迁移。iframe、Shadow DOM、图标字体和第三方组件有独立适配边界。首版不含可视化拾取或特定编辑器适配；候选包不自动发布或部署。

## 选择器诊断与主页范围

每条规则旁可点击「诊断选择器」，或在规则区点击「选择器穿透查询」。输入待诊断的本站公开页面与 `.class`、`#id` 或选择器，先加载页面，再查询。结果列出真正承载文字的元素、当前字体、匹配数量，以及普通/强制覆盖能否影响所示文字。采用候选只填入草稿，确认目标字体与范围后仍须保存。

多个独立目标用**半角逗号**：`.a, .b, #title`；空格 `.a .b` 表示后代，`.a.b` 表示同一元素同时有两个 class，`.a > .b` 表示直接子元素。绿野主页标题可查询 `.hero`，候选可能为 `.hero > .headline`；不要把互不嵌套的 class 用空格串起来。

主页不是独立页面资源，请在「页面范围」直接选择「主页（站点根路径 /，不含分页）」，而非在「指定页面」列表查找。诊断默认不运行页面脚本；动态内容需要显式选择运行脚本并重新加载。独立 iframe、Shadow DOM、跨域页面与实际字体缺字不由普通 DOM 覆盖测试保证。
