# KhonFontBook 安装与使用

版本 0.1.0 · 作者 KhonChi

KhonFontBook 用于管理 Halo 站点的字体，为中英文设置搭配，并通过选择器将字体应用到主题中的指定文字。

## 安装

运行环境为 Halo 2.27.0、Java 21 和 Linux。字体解析依赖 Python ≥3.11、FontTools 4.67.0、Brotli 1.2.0。

1. 备份 Halo 数据和附件，将插件 JAR 上传到 Console「插件」，然后启用。
2. 在运行 Halo 的主机或容器中安装 Python 环境：

   ```sh
   python3 -m venv /opt/khon-font-book/python
   /opt/khon-font-book/python/bin/pip install 'fonttools==4.67.0' 'Brotli==1.2.0'
   /opt/khon-font-book/python/bin/pip check
   ```

   使用容器时，Python 也要安装在容器内。仓库的 `scripts/halo-fonts/` 提供 Dockerfile 和 requirements 示例。
3. 在插件「字体资源」设置中填写 Python 的绝对路径，或设置环境变量 `KHON_FONT_BOOK_PYTHON`。工作台显示「解析环境就绪」后即可导入。
4. 在 Halo 中创建字体专用的 local 附件策略，例如 `khon-font-book-local`。使用目录 `khon-font-book`、大小上限 `20MB`、`allowedFileTypes: []`，再在插件设置中选择该策略。这里的空列表让字体通过附件类别检查，字体签名和元数据由插件检查；保留站点原有的默认策略与 CORS 配置。
5. 配置 Halo 的 `external-url`，确保 Halo 能匿名读取该地址下的本地 `/upload/` 字体文件。当前支持同源本地附件，不支持私有文件、跨域存储或重定向地址。

## 导入与配对

在「工具 → KhonFontBook → 字体库」导入 WOFF2 或 TrueType TTF，填写字体来源和许可。插件保留原格式，读取字重、样式及字符覆盖，预览时按需加载文件。

需要中英搭配时，在「配对方案」中分别选择中文与西文字体，使用两侧共有的字重和样式，并设置回退字体。也可以在规则中直接选择一个字体族。

支持静态单色字体，单文件上限 20 MiB。暂不支持 OTF、字体集合、变量字体、颜色字体、格式转换和自动子集化。插件不附带字体文件，元数据检查不能代替字体授权确认。

## 设置主题规则

在「主题规则」中新建规则，选择主题、页面范围和字体目标，填写选择器并保存。然后到插件设置中开启「主题字体应用」，刷新对应页面。

| 写法 | 含义 |
| --- | --- |
| `.a, .b, #title` | 用半角逗号选择多个独立目标 |
| `.a .b` | 选择 .a 内部的 .b 后代 |
| `.a.b` | 同一元素同时具有两个 class |
| `.a > .b` | 选择 .a 的 .b 直接子元素 |

选择器支持标签、class、ID、`> + ~` 和逗号列表；不支持属性选择器、伪类、伪元素及通配符。最多 1024 字符、16 个选择器，每个选择器最多 32 个节点。

页面范围选「主页」时，只在站点根路径 `/` 应用，不包括归档和分页。指定文章或页面时，规则绑定该内容的 ID。高级编译中的页面选项只用于检查，不会改变已保存规则的范围。

默认只修改 font-family；字重和 !important 可按需要设置。若外层 class 没有改变文字，可先用「选择器穿透查询」查找文字所在的子元素，测试覆盖效果，再采用结果。采用只会填入草稿，保存规则后才生效。

诊断页面默认不运行脚本。启用脚本后，主题脚本与后台同源，可能访问本站登录态和资源，只应对信任的主题启用。字体是否加载成功仍需检查实际页面；iframe、Shadow DOM 及主题自己的内联样式可能需要另行处理。

## 停用与删除

关闭注入或停用规则后，刷新页面即可停止对应的字体应用。通过接口主动加载字体的主题或插件，需要在接入方取消引用。

删除前会检查内部和已登记的外部引用。删除插件中的字体记录会保留 Halo 附件；要移除文件，还需在附件管理中删除，并按需清理缓存与备份。未登记的外部使用无法自动查出。
